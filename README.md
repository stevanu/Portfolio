# Portofolio Stevanu Dika Pratama

React + Vite + Tailwind CSS 3. Jalankan: `npm install` lalu `npm run dev`.

## Struktur (atomic design dengan nama sendiri)
- `src/elements/`  : bagian terkecil (Button, Chip, Badge, Heading)
- `src/fragments/` : gabungan elements (ProjectCard, SkillGroup, FilterBar, ...)
- `src/sections/`  : blok halaman utuh (HeroSection, ProjectsSection, Navbar, ...)
- `src/layouts/`   : kerangka halaman (MainLayout: navbar, konten, footer)
- `src/pages/`     : satu file per halaman/rute
- `src/data/profile.js` : semua isi konten, ubah di sini
